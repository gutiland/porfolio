# Portfolio personal

Primera versión con React, Vite y SCSS.

## Desarrollo
```sh
npm install
npm run dev
```

## Producción
```sh
npm run build
npm run preview
```

## Antes de publicar
- Completar nombre, email, LinkedIn, GitHub y CV. El contacto muestra un aviso provisional.
- Revisar que la descripción refleje tu aportación personal.
- Sustituir la representación conceptual por capturas reales si procede.
- Añadir versión inglesa y selector de idioma.
- Comprobar la demo, móvil, teclado y enlaces.
- Añadir enlace al repositorio del proyecto.

No hay formulario que recopile datos. La vista del entrenamiento es una composición ilustrativa, no una captura de la aplicación.

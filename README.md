# Portfolio · Alejandro Gutiérrez Moreno

Portfolio personal orientado a oportunidades de desarrollo frontend y full stack.

## Tecnologías

- React y JavaScript.
- Vite.
- SCSS.
- Prettier.

## Contenido

- Presentación y trayectoria profesional.
- Experiencia de prácticas en Talentfyseek.
- Proyectos con capturas y enlaces a su código.
- Contacto, LinkedIn, GitHub y CV descargable.
- Diseño adaptable a móvil y escritorio.

## Proyectos incluidos

### Clases a tu ritmo

Aplicación full stack de entrenamiento con React, Node.js, Express y MongoDB.
Incluye clases organizadas por tracks e indicaciones sincronizadas con el vídeo.

### Restaurante React

Frontend con navegación, modo oscuro y formulario de reservas con validación.
Las reservas son de demostración y no se guardan. Disponible mediante su repositorio.

### Mercedes · HTML y CSS

Proyecto educativo de maquetación responsive inspirado en Mercedes-Benz,
sin afiliación con la marca. Incluye enlaces a demo y código.

## Ejecutar en local

```bash
npm install
npm run dev
```

## Comandos

```bash
npm run build
npm run preview
npm run format
npm run format:check
```

## Organización

- `src/components/`: componentes con sus archivos SCSS.
- `src/data/projects.js`: información de los proyectos.
- `src/styles.scss`: estilos globales.
- `src/styles/`: variables compartidas.
- `public/`: imágenes y CV.

## Proceso de desarrollo

He utilizado Codex como apoyo para crear la base del portfolio, organizar
componentes y revisar código. Después he ido personalizando los contenidos
y adaptando la implementación.
